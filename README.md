Sizzle & Serve — a 2D cooking game. Take orders from the board, chop and cook ingredients on the stove and cutting board, build dishes on the plate, and serve them before the ticket timer runs out. Three lives, a 90-second day, and a faster rush each day.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 to play in a desktop browser. No network requests, no build step — plain static files under game/.
